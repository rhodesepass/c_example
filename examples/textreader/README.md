# textreader

这个示例展示双缓冲buffer+按键读取+ttf渲染，实现了一个基本的文本阅读器。

运行前请在“运行目录”创建 `./fonts/` 并放入至少一个字体文件（`.ttf` 或 `.otf`）。如果 `./fonts/` 下没有任何字体，程序会报错并直接退出（不会开始渲染）。

按键约定：
- `KEY_1` 上翻页
- `KEY_2` 下翻页
- `KEY_3` 进入菜单 / 确认
- `KEY_4` 返回 / 退出（退出前确认）

阅读进度与书签会保存到运行目录 `./textstate/<文本文件名>.state`。

这是完全AI编写的示例。使用RIPER-5协议，GPT5.2模型，提示词为：

```
请你在text reader中实现一个文本阅读器。需要处理utf-8文字，需要使用ttf渲染（有中文）。约定按1上翻页，按2下翻页，3进入菜单，按4退出（退出前确认）。在屏幕下方显示当前页数。
在
工作路径/textstate下，通过文本文件的文件名记录阅读位置和书签。

菜单用简单的文字实现一个就可以了，包括文本大小设定，跳转到某页（只使用四个按键做数字编辑），记录/查看书签，设置字体（可选择工作路径下的ttf/otf文件）
```
